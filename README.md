# 🏖️ Туристическое Агентство Онлайн

Полнофункциональное веб-приложение туристического агентства с системой бронирования, отзывов и поддержки клиентов.

## 📋 Описание проекта

Это веб-приложение представляет собой современную платформу для туристического агентства, включающую:

- **Фронтенд**: Современный интерфейс на HTML, CSS, JavaScript с использованием Bootstrap
- **Бэкенд**: Spring Boot приложение на Java с REST API
- **База данных**: H2 Database (встроенная)
- **Аутентификация**: JWT токены
- **Система ролей**: Пользователи и администраторы

## ✨ Основные возможности

### Для пользователей:
- 📖 Просмотр каталога туров с фильтрацией
- 🏷️ Бронирование туров
- 💳 Оплата бронирований
- ⭐ Оставление отзывов о турах
- 📱 Личный кабинет с историей заказов
- 💬 Система поддержки клиентов
- 🔔 Уведомления о статусе заказов

### Для администраторов:
- 👥 Управление пользователями
- 🏔️ Управление турами (добавление, редактирование, удаление)
- 📊 Управление бронированиями
- 🎧 Обработка обращений в поддержку
- 📈 Просмотр статистики

## 🚀 Установка и запуск

### Предварительные требования:
- Java 17 или выше
- Maven 3.6+
- Веб-браузер

### Шаги установки:

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Atamurat2004/My_New_Project_Travel_Agency.git
   cd My_New_Project_Travel_Agency
   ```

2. **Запустите бэкенд:**
   ```bash
   cd Travel_Agency
   mvn spring-boot:run
   ```
   Приложение будет доступно по адресу: `http://localhost:8080`

3. **Откройте фронтенд:**
   - Откройте файл `Frontend/public/index.html` в браузере
   - Или запустите локальный сервер (например, Live Server в VS Code)

## 🔐 Аутентификация

### Роли пользователей:
- **ROLE_USER** - обычные пользователи
- **ROLE_ADMIN** - администраторы

### Тестовые аккаунты:
- **Администратор**: admin@example.com / password
- **Пользователь**: user@example.com / password

## 📊 API Endpoints

### Аутентификация:
- `POST /api/auth/register` - Регистрация
- `POST /api/auth/login` - Вход

### Туры:
- `GET /api/tours` - Получить все туры
- `POST /api/admin/tours` - Создать тур (админ)

### Бронирования:
- `POST /api/bookings` - Создать бронирование
- `GET /api/bookings/my` - Мои бронирования
- `PUT /api/bookings/{id}/pay` - Оплатить бронирование

### Поддержка:
- `POST /api/support` - Создать обращение
- `GET /api/support/my` - Мои обращения
- `POST /api/support/{id}/reply` - Ответить на обращение

## 🔧 Разработка

### Добавление новых функций:
1. Создайте модель в `model/`
2. Добавьте репозиторий в `repository/`
3. Создайте сервис в `service/`
4. Добавьте контроллер в `controller/`
5. Обновите фронтенд в `Frontend/`

### База данных:
- Автоматическое создание таблиц при запуске
- Начальные данные загружаются из `data.sql`
- Поддержка миграций через JPA
