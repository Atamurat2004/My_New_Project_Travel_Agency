# Система поддержки турагентства

## Описание

Система поддержки интегрирована в личный кабинет пользователя и позволяет клиентам обращаться к администраторам по различным вопросам, включая проблемы с бронированием, оплатой и технические вопросы.

## Архитектура

### Backend (Spring Boot)

#### Модели данных:
- **SupportTicket** - основная модель обращения
- **SupportMessage** - сообщения в рамках обращения

#### Основные компоненты:
- **SupportController** - REST API для управления обращениями
- **SupportService** - бизнес-логика обработки обращений
- **SupportTicketRepository** - доступ к данным обращений
- **SupportMessageRepository** - доступ к сообщениям

### Frontend

Система поддержки интегрирована в личный кабинет пользователя как отдельная вкладка "🎧 Поддержка".

#### Функциональность:
- Создание нового обращения
- Просмотр истории обращений
- Детальный просмотр обращения в модальном окне
- Отправка дополнительных сообщений к обращению

## API Endpoints

### Для пользователей:
- `POST /api/support` - создать новое обращение
- `GET /api/support/my` - получить список своих обращений
- `GET /api/support/{id}` - получить детали обращения
- `GET /api/support/{id}/messages` - получить сообщения обращения
- `POST /api/support/{id}/reply` - отправить ответ к обращению

### Для администраторов:
- `GET /api/support/admin/all` - получить все обращения
- `GET /api/support/admin/{id}` - получить детали обращения
- `PUT /api/support/admin/{id}/status` - изменить статус обращения
- `POST /api/support/admin/{id}/message` - отправить сообщение от имени поддержки
- `POST /api/support/admin/{id}/refund-request` - создать запрос на возврат
- `POST /api/support/admin/{id}/refund-approve` - одобрить возврат
- `POST /api/support/admin/{id}/refund-reject` - отклонить возврат

## Использование

### Для пользователей:
1. Войдите в личный кабинет
2. Перейдите на вкладку "🎧 Поддержка"
3. Заполните форму создания обращения
4. Просматривайте историю обращений
5. Открывайте детали обращения для просмотра ответов

### Для администраторов:
1. Войдите как администратор
2. Используйте API endpoints для управления обращениями
3. Отвечайте на обращения пользователей
4. Обрабатывайте запросы на возврат средств

## Установка и запуск

1. Убедитесь, что база данных содержит таблицы поддержки (см. `support_tables.sql`)
2. Запустите Spring Boot приложение
3. Система поддержки будет доступна в личном кабинете пользователей

## Особенности

- Полная интеграция с системой аутентификации
- Автоматическое логирование действий через AuditLogService
- Поддержка различных категорий обращений
- Система статусов обращений (OPEN, IN_PROGRESS, CLOSED)
- Возможность запроса возврата средств для оплаченных туров
